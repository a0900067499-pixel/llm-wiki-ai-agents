id：S1　title："What is an Agent? (Hugging Face Agents Course, Unit 1)"　url：https://huggingface.co/learn/agents-course/unit1/what-are-agents　retrieved：2026-11-23　note：以 WebFetch 擷取後的重點筆記（改寫，非原文全文）。ingest 後不可修改。
  • Alfred analogy: Alfred receives "I would like a coffee", understands the language, reasons and plans (go to kitchen, use coffee machine, brew, bring back), uses tools he knows, delivers coffee. He has agency because he can affect his environment.
  • Definition: an agent is a system that uses an AI model to interact with its environment to reach a user-defined goal; combines reasoning, planning and action execution, often via external tools.
  • Two parts: Brain (AI model: reasoning, planning, choosing actions) and Body (capabilities and tools: what it is equipped to do; humans can't fly but can walk/run/jump/grab).
  • Agency spectrum table (says it is taken from smolagents conceptual guide): ☆☆☆ simple processor; ★☆☆ router; ★★☆ tool caller; ★★★ multi-step agent; ★★★ multi-agent.
  • Models: most commonly an LLM (text in, text out), e.g., GPT-4, Llama, Gemini; VLMs can also be the core model.
  • LLMs can only generate text; actions happen through tools (e.g., image generation tool). One action may use several tools, so actions and tools are distinct.
  • Tools determine capability; example send_message_to lets an assistant send email. Tool design strongly affects agent quality.
  • Examples: personal virtual assistants (Siri, Alexa, Google Assistant), customer service chatbots (answer, troubleshoot, open tickets, complete transactions), video game NPCs.
  • Takeaway: an agent uses an AI model (typically LLM) as reasoning engine to understand natural language, reason and plan, and interact with the environment (gather info, act, observe results).
