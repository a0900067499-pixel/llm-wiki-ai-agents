id：S3　title："LLM Powered Autonomous Agents (Lilian Weng, Lil'Log)"　url：https://lilianweng.github.io/posts/2023-06-23-agent/　date：2023-06-23　retrieved：2026-11-23　note：以 WebFetch 擷取後的重點筆記（改寫，非原文全文）。ingest 後不可修改。
  • LLM is the agent's brain, complemented by three components: planning, memory, tool use.
  • Planning / task decomposition: Chain of Thought (think step by step); Tree of Thoughts (multiple thoughts per step, searched as tree via BFS/DFS); LLM+P (LLM translates to PDDL, classical planner solves, translates back). Decomposition by simple prompting, task-specific instructions, or human input.
  • Planning / self-reflection: ReAct (Thought, Action, Observation interleaved); Reflexion (binary reward, verbal self-reflections stored in memory, heuristics detect inefficient planning or hallucination, reset trial); Chain of Hindsight; Algorithm Distillation.
  • Memory mapping: sensory memory → embeddings of raw input; short-term memory → in-context learning limited by context window; long-term memory → external vector store queried at retrieval time.
  • Fast retrieval (MIPS / approximate nearest neighbour): LSH, ANNOY, HNSW, FAISS, ScaNN.
  • Tool use: MRKL (LLM routes to expert modules like calculators; struggled to extract right arguments for verbal math → knowing when/how to use tools matters); TALM & Toolformer (fine-tune to call APIs); ChatGPT plugins & function calling; HuggingGPT (task planning, model selection, task execution, response generation); API-Bank benchmark (53 tools, 264 dialogues; levels: call API, retrieve API, plan across calls).
  • Case studies: ChemCrow (13 chemistry tools; LLM-based eval rated it ≈ GPT-4, human experts strongly preferred ChemCrow → LLMs may be poor judges of their own performance in expert domains); scientific discovery agent with risks; Generative Agents (25 characters in sandbox; memory stream, retrieval by recency/importance/relevance, reflection, planning); AutoGPT (much code for output parsing, reliability issues); GPT-Engineer.
  • Challenges: finite context length; long-term planning and task decomposition (hard to recover from unexpected errors); reliability of natural language interface (formatting errors, refusing instructions).
