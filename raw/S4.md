- Reasoning (e.g., chain-of-thought) and acting (e.g., action plan generation) had mostly been studied separately.
- ReAct interleaves reasoning traces with task-specific actions.
- Reasoning helps form, track and update plans and handle exceptions; actions let the model gather information from external sources (knowledge bases, environments).
- HotpotQA (QA) and FEVER (fact verification): ReAct uses a simple Wikipedia API and reduces hallucination and error propagation seen in chain-of-thought.
- ALFWorld and WebShop (interactive decision making): absolute success rate gains of 34% and 10% over imitation and reinforcement learning methods, prompted with only one or two in-context examples.
- Produces more interpretable, trustworthy task-solving trajectories.
