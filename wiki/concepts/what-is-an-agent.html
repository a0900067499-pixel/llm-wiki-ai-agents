什麼是 AI Agent？

title：什麼是 AI Agent？　sources：[S1, S2, S6]　updated：2026-11-23

一句話定義

  • Agent 是「用 AI 模型和環境互動、去達成使用者設定之目標」的系統，結合推理、規劃與執行行動，通常透過外部工具。[S1]
  • 工程上的精簡定義：LLM 的輸出控制了程式的流程。[S2]
  • 從使用者角度：agent 是能「代替你、相對獨立地完成任務」的系統。[S6]

比喻：管家 Alfred

  • 你說「我想喝咖啡」，Alfred 聽懂 → 規劃（去廚房、用咖啡機、煮、端回來）→ 使用他會用的工具 → 把咖啡交給你。[S1]
  • 他之所以有「代理能力」（agency），是因為他能改變周遭環境。[S1]

大腦與身體

  • 大腦＝AI 模型：負責推理、規劃、決定下一步做什麼。[S1]
  • 身體＝能力與工具：agent 能做什麼，取決於它被配備了哪些工具（人不會飛，但能走、跑、抓）。[S1]
  • LLM 本身只能產生文字；要「做事」必須透過工具，例如呼叫生圖工具、寄信函式 send_message_to。[S1]

什麼「不是」agent

  • 只用 LLM、但沒讓 LLM 控制流程的應用不算 agent：單純聊天機器人、單次 LLM 呼叫、情緒分類器。[S6]
  • agent 的關鍵特徵：由 LLM 管理流程執行、判斷何時完成、修正自己的動作，失敗時能停下來把控制權交還使用者。[S6]

常見例子

  • 個人助理（Siri、Alexa、Google Assistant）、客服機器人（回答、排除問題、開工單、完成交易）、遊戲 NPC。[S1]
